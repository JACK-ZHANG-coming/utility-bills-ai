# 2026-08-07 工作日志

## 水电费快捷计算静态网页

- 创建了 `index.html`，包含电费计算和水费计算两个 Tab 页
- 每个页面 4 个输入框 + 结果展示行
- 输入框1/2 左侧带可编辑日期（YYYY-MM-DD），输入框2 日期默认今天
- 输入框3 自动计算（输入框2 - 输入框1）：当输入框1或2有值时只读+自动计算，两者均无值时允许手动输入
- 电费单价默认 0.55 元/度，水费单价默认 2.8 元/吨
- 结果 = 输入框3 × 输入框4，保留完整小数位（使用 toPrecision(12) 去除浮点误差）
- 纯前端实现，单 HTML 文件，无外部依赖

## 增加 localStorage 本地存储功能

- 每次输入变更时自动将所有字段（日期、度数、用量、单价）以 JSON 格式保存到 localStorage
- 存储键按页面分离：`utility-bills-electricity`（电费）、`utility-bills-water`（水费），互不干扰
- 页面加载时自动从 localStorage 恢复数据并回填表单，显示"已恢复"Toast 提示
- 新增"清除已保存数据"按钮（红色样式），带确认弹窗，一键清除两个页面的缓存
- "重置"按钮同时清除对应页面的 localStorage
- 保存时显示"✓ 已自动保存"淡入淡出提示
- 日期字段使用 change 事件监听，数值字段使用 input 事件监听

## 改为手动保存机制

- 移除所有自动保存行为：input/change 事件仅触发实时计算，不再调用 saveToStorage
- 新增"保存数据"按钮（蓝色主按钮），点击时调用 manualSave 持久化当前页面数据
- 每次成功保存后，记录保存时间戳（savedAt 字段，ISO 格式存储）
- 新增"上次保存时间"状态栏（显著位置，结果卡片下方），显示格式 YYYY-MM-DD HH:mm:ss
- 状态栏含状态指示灯：灰色圆点=尚未保存，绿色圆点=已保存
- 页面加载时从 localStorage 读取 savedAt 并显示上次保存时间
- "清除已保存数据"和"重置"操作同时重置保存时间显示为"尚未保存"
