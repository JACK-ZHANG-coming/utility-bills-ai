## 水电费快捷计算静态网页

- 创建了 `index.html`，包含电费计算和水费计算两个 Tab 页
- 每个页面 4 个输入框 + 结果展示行
- 输入框1/2 左侧带可编辑日期（YYYY-MM-DD），输入框2 日期默认今天
- 输入框3 自动计算（输入框2 - 输入框1）：当输入框1或2有值时只读+自动计算，两者均无值时允许手动输入

- 纯前端实现，单 HTML 文件，无外部依赖

## 修复侧边栏收起/展开两个 Bug

- Bug1（收起后打不开）：根因是收起时标题用 `opacity:0` 仍占空间，加上 padding+按钮宽度超过 52px 被 `overflow:hidden` 裁剪，按钮无法点击；移动端更严重（width:0 + header pointer-events:none）
- 修复：标题改用 `display:none` 彻底移出布局；收起时 header 居中、padding 缩小；按钮宽度 36px 足以容纳
- Bug2（图标不明显）：按钮从 28px 灰色白底改为 32px 深色浅灰底，hover 变靛蓝高亮；收起时按钮放大至 36px、靛蓝实色背景+白色图标+阴影，对比度极高
- 移动端 ≤480px：收起宽度从 0 改为 52px，header 保持 `opacity:1; pointer-events:auto`，确保按钮始终可点击
- 640px 断点：收起宽度从 48px 改为 52px，避免按钮被裁剪
