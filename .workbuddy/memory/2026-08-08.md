## 本地仪表盘调试 - file:// 协议问题修复
- **问题**：本地打开 `file:///Users/.../stats-server/dashboard.html` 登录时永远提示"Token 无效"
- **根因**：`file://` 协议下浏览器禁止页面 JS `fetch()` 跨源访问 HTTP/HTTPS（Chrome 直接 block "已屏蔽：来源"），所以 `verifyToken` 永远走 catch 分支返回 ok=false
- **解决方案**：给 `server.js` 增加 `/dashboard` 静态文件路由（同时支持 `/dashboard.html`），让 dashboard 和 API 同源（同端口 3210），绕过 CORS
- 改动两处：① 顶部 `const fs = require('fs');` ② 在 `/api/health` 路由前增加 `/dashboard` 分支返回 `__dirname + '/dashboard.html'`
- **本地启动命令**：`cd stats-server && ACCESS_TOKEN=<你的token> node server.js`
- **访问地址**：`http://127.0.0.1:3210/dashboard`（**不是** file:// 也不是 :8080）
- **生产环境不受影响**：生产环境 dashboard.html 由 Nginx `try_files` 直接 serve，本路由只在 Node 进程内部生效
- 验证：dashboard 200、/api/stats 无 token 401、错误 token 401、正确 token 200、CORS preflight 204
